Nemo's Reef Revival helps you play Nemo's Reef again with a server you run at home. Build your reef, reconnect with familiar fish and make room for a little nostalgia.

Find your way back

A home for your reef.

Choose one way to run the server,
then connect your Android game.

01 / DOCKER

Let your NAS do the work.

Run the prebuilt image on a NAS, mini PC or other Docker host. Keep your reef available while your laptop is switched off.

Docker setup ↗ Using OpenMediaVault? Start here ↗
01 / WINDOWS

Start on your own PC.

Run the server directly on Windows with Python. Your PC needs to stay on and awake while you play.

Windows setup ↗ Download the server & patcher ZIP ↓
02 / CONNECT YOUR GAME

Reef, meet Android.

With the server running, patch a copy of your original APK to connect to it. Install that copy on your Android device, then head back underwater.

Patch & install the APK ↗

You'll need your own original Android 1.8.1 APK and a device that supports 32-bit apps. Game files aren't provided.
