Welcome back to the reef!

Nemo's Reef Revival is a fan-made server for the Android version of Nemo's Reef.

The project supports saved reefs, buying and placing fish and plants, story quests, and visiting friends on the same server.

You host the server at home, then patch your copy of the game to connect to it. Your phone or tablet connects over your home network. The guides below explain each step.

Still in development

Some features are unfinished, and there will be bugs. Co-op quests aren't supported yet. Check the game status page for the full list, and back up your save before updating.

Game status & known issues ↗

Before you start

  • Your own original Android 1.8.1 APK.
  • An Android device that supports 32-bit apps.
  • A PC or Docker host to run the server while you play.

We don't provide APKs or other game files.
